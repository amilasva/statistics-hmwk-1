How does it work?

A private key is an integer k. The corresponding public key is calculated as Q = kG, where G is a point on an elliptic curve.

Scalar multiplication means repeatedly adding the point G to itself. In this example, all calculations are performed modulo 17.

Point multiplication steps

For two different points, the slope is λ = (y₂ − y₁)(x₂ − x₁)⁻¹ mod 17. For point doubling, λ = 3x₁²(2y₁)⁻¹ mod 17. The resulting coordinates are x₃ = λ² − x₁ − x₂ and y₃ = λ(x₁ − x₃) − y₁, both modulo 17. The exponent −1 represents a modular inverse.

Statistical Observations

Observations from different private keys on the curve y² ≡ x³ + 7 (mod 17).

Coordinate Distribution

The x and y coordinates are not selected randomly. Each public key must satisfy the elliptic curve equation. For example, 3G = (5, 9) and 6G = (5, 8) share the same x-coordinate but have different y-coordinates.

Repetition and Periodicity

The generator G = (1, 5) has order 9, meaning that 9G is the point at infinity. The sequence then repeats, so 10G = G. This limits the number of distinct points generated by this base point.

Changes in the Private Key

Increasing k by 1 produces the next point through elliptic curve addition. However, the numerical differences between consecutive coordinates are not constant. For example, 2G = (2, 10), 3G = (5, 9) and 4G = (12, 1).

Frequency of Coordinates

In the eight non-identity multiples of G, the x-coordinates occur in pairs. This happens because P and −P have the same x-coordinate but opposite y-coordinates modulo 17. The y-coordinates in this dataset are all distinct.

Statistical Dependence

The coordinates are mathematically related through the curve equation, but this does not necessarily imply a strong linear correlation. Mean, standard deviation and correlation describe the numerical dataset without capturing its complete algebraic structure.

Relationship to Cryptographic Properties

Elliptic curve scalar multiplication is deterministic: the same private key and generator always produce the same public key.

The main security principle is the Elliptic Curve Discrete Logarithm Problem (ECDLP). Computing Q = kG is efficient, while recovering k from Q is computationally difficult for appropriately chosen large cryptographic groups.

Scalar multiplication differs from a cryptographic hash function. Hash functions are designed to provide strong diffusion, whereas elliptic curve multiplication preserves an algebraic relationship:

(a + b)G = aG + bG

Consecutive private keys therefore produce mathematically related public keys, even when their coordinates look very different. Unlike a secure hash function, scalar multiplication is not designed to provide the strict avalanche effect.

In this small example, every possible private key can easily be tested. The purpose is to understand the mathematics, not to implement a secure cryptographic system.
